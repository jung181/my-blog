## 텍스트 꾸미기

**굵게**, *기울임*, ***굵은 기울임***, ~~취소선~~, `인라인 코드`를 쓸 수 있어요.
한글 사이에서도 **굵게**처럼 붙여 쓸 수 있습니다.

줄 끝에 공백 두 개를 넣으면  
이렇게 줄이 바뀝니다.

별표를 그대로 쓰고 싶으면 \*역슬래시\*를 앞에 붙이세요.

## 코드 블록

```js
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('독자') + ' <b>태그는 글자로 보여요</b>');
```

아주 긴 줄은 코드 블록 안에서만 가로로 스크롤됩니다:
